# 🖼️ Image Gallery

A modern and responsive **Image Gallery Web App** built using **HTML, CSS, and JavaScript**. This project allows users to search and explore images through a clean and interactive interface.

## ✨ Features

* 🔍 **Image Search** — Search for images using keywords.
* 🗂️ **Category Filtering** — Browse images based on different categories.
* 🔄 **Refresh Button** — Refresh the gallery and load new images.
* ➕ **Load More** — Dynamically load additional images without refreshing the page.
* 👁️ **View Image** — Open and view images in a larger view.
* ⬇️ **Download Image** — Download images with a confirmation before downloading.
* 💀 **Skeleton Loading** — Smooth loading animation while images are being fetched.
* 📱 **Responsive Design** — Works across desktop, tablet, and mobile screen sizes.
* ⚡ **Dynamic JavaScript Functionality** — Images and gallery content are updated dynamically using JavaScript.

## 🛠️ Technologies Used

* **HTML5** — Structure and semantic elements
* **CSS3** — Styling, layout, animations, and responsiveness
* **JavaScript** — DOM manipulation, API integration, search, filtering, and dynamic content
* **Image API** — Fetching images dynamically
